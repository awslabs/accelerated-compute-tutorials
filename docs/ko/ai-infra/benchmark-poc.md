## 다룰 내용 (메모)

### 측정 기준 정의
- 추론: Latency (TTFT, TPOT), Throughput (tok/s), Cost per token
- 학습: MFU, 수렴 시간, GPU 활용률

### 비교 테스트 설계
- 동일 워크로드 → 다른 하드웨어 A/B 테스트
- 변수 통제 (배치 사이즈, 시퀀스 길이, 동시 요청 수)

### 실전 PoC 절차
- 환경 셋업 (AMI, 컨테이너, 프레임워크 버전 고정)
- 워밍업 → 측정 → 통계 처리
- 판단 기준 (목표 대비 달성률)

### 결과 리포팅
- 고객 보고용 포맷
- 시각화 (비교 차트, 비용 분석표)
- 의사결정 근거 문서화
