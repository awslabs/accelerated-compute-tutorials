## 다룰 내용 (메모)

### 비용 최적화
- Spot, Capacity Blocks, Savings Plan 전략
- 워크로드별 구매 옵션 조합

### 모델 경량화
- 더 작은 모델 검토 (같은 품질, 적은 자원)
- Knowledge Distillation
- 파인튜닝 없이 정확도 올리기 (프롬프트 엔지니어링, RAG)

### 양자화 심화
- 품질 vs 비용 트레이드오프
- 양자화 레벨별 실측 성능 비교

### 멀티노드 스케일링
- TP/PP/EP/DP 전략 선택
- EFA, NCCL 설정
- 노드 수 대비 선형 스케일링 확인 방법
