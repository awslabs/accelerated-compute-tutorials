# Domain Intelligence

고객 데이터로 파인튜닝한 산업·도메인 특화 모델은, 실제로 중요한 태스크에서 훨씬 큰 독점 모델보다 뛰어난 성능을 내면서도 가치 대비 비용(cost per value)은 크게 낮춥니다. Domain Intelligence는 Frugal AI의 "think big" 확장입니다 — 쓰지도 않는 범용 규모에 비용을 지불하는 대신, 도메인에 맞춰 더 작고 빠르고 우수한 모델을 구축합니다.

## 이 섹션에서 다룰 내용

- 산업·도메인 특화 성능을 위한 오픈웨이트 모델 파인튜닝
- 도메인 모델을 위한 데이터 큐레이션 및 평가
- 도메인 모델의 비용 효율적 서빙 및 최적화
- 더 작은 특화 모델이 더 큰 범용 모델을 능가하는 경우
