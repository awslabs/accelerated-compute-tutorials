**교육 목표**

- Self-hosted AI 트렌드 이해 — 데이터 주권, 비용 통제, 커스터마이징 요구에 따른 인프라 전략
- EKS 기반 통합 AI 플랫폼 구성 — 학습/추론/에이전트를 하나의 클러스터에서 운영
- Agentic AI 프로덕션 배포 — 자율적으로 추론·계획·실행하는 AI Agent의 배포 아키텍처 설계
- 비용 및 컴퓨트 최적화 — 칩 선택, 모델 양자화(Quantization), Spot, 스토리지 최적화, Hybrid 전략
- GenAI Agent 플랫폼 배포 실습
