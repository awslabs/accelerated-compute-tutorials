# Neuron Foundations (NFD)

!!! note

## 🎯 코스 개요

AWS Trainium 칩의 하드웨어 아키텍처, Neuron 소프트웨어 스택, 그리고 실제 고객 사례를 통해 AWS AI Chip의 가치를 빠르게 파악할 수 있는 이론 중심 과정입니다.
