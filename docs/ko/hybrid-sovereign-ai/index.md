# Hybrid & Sovereign AI

**Hybrid AI** 는 파편화된 온프레미스·엣지·타 클라우드 컴퓨트를 AWS와 통합하여, AI 워크로드를 하나의 일관된 운영 모델 아래로 모읍니다.

**Sovereign AI** 는 데이터 주권, 국가 정책, 언어적 필요가 요구되는 경우를 위해 국내(in-country)·프라이빗 VPC 내 셀프 호스팅 모델과 학습을 더합니다 — 국가 AI 프로그램과 AI Factory 이니셔티브를 포함합니다.

## 이 섹션에서 다룰 내용

- 온프레미스, 엣지, 타 클라우드 컴퓨트와 AWS 연결
- 국내(in-country)·VPC 내 셀프 호스팅 모델 배포 및 학습 패턴
- 데이터 주권 및 컴플라이언스 기반 아키텍처
- 국가 AI 프로그램 및 대규모 이니셔티브를 위한 용량 계획
