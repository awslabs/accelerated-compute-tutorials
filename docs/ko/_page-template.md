## 적용된 CSS 규칙 (extra.css에서 자동 처리)

| 항목 | 규칙 | 비고 |
|------|------|------|
| 본문 글자 크기 | `0.76rem`, `line-height: 1.7` | 한글 기준 최적화 |
| H2 제목 | `font-weight: 700`, `font-size: 1.4em`, accent 밑줄, `margin-top: 2.4em` | 본문과 확실히 구분 |
| 테이블 | 페이지 가운데 정렬 + 셀 글자 가운데 정렬, 셀 테두리 있음 | CSS 자동 적용 — 마크다운에서 `:---:` 불필요 |
| GitHub Star 배너 | 우측 고정 세로 배너 (overrides/main.html) | 전 페이지 자동 적용 |

## 마크다운 작성 컨벤션

### 1. 페이지 구조

```markdown
---
title: [페이지 제목]
description: [한 줄 설명 — SEO + 카드 미리보기용]
---

# [페이지 제목]

[1~2문장 도입부 — 이 가이드가 무엇을 다루는지]

---

## 1. [첫 번째 섹션]

...본문...

---

## 2. [두 번째 섹션]

...본문...

---

## 관련 가이드

| 가이드 | 내용 |
|--------|------|
| [가이드 이름](상대경로.md) | 한 줄 설명 |

---

*Author: [이름] · [직책]*
```

### 2. 섹션 번호 규칙

- H2 (`##`)에 **아라비아 숫자** 붙임: `## 1.`, `## 2.`, ...
- H3 (`###`)에는 번호 안 붙임 — 소제목은 텍스트만
- 마지막 "관련 가이드" 섹션에는 번호 안 붙임

### 3. Admonition 사용 규칙

| 타입 | 용도 | 예시 |
|------|------|------|
| `!!! tip "제목"` | 실전 판단 팁, 핵심 인사이트 | "핵심", "실전 판단" |
| `!!! warning "제목"` | 주의사항, 흔한 실수 | "주의", "흔한 실수" |
| `!!! note "제목"` | 보충 설명, 참고 | "참고", "추가 설명" |

- 섹션 끝에 배치 (본문 흐름 끊지 않게)
- 한 섹션당 최대 1~2개

### 4. 테이블 작성 규칙

- 헤더 첫 열: **구분 기준** (지표, 모델, 인스턴스 등)
- 볼드: 핵심 셀만 (`**값**`)
- 이모지 사용 가능: ✅ ❌ ⚠️ (지원 여부 매트릭스)
- 너무 넓은 테이블(7열+)은 분할 고려

### 5. 코드 블록

- 공식/수식: ` ``` ` (언어 지정 없이)
- 실행 코드: ` ```python `, ` ```bash ` 등 언어 명시
- Mermaid 다이어그램: ` ```mermaid `

### 6. 내부 링크

- 같은 섹션 내: `[이름](파일명.md)` (상대 경로)
- 다른 섹션: `[이름](../섹션/파일명.md)`
- TODO 링크: `[이름](파일명.md) ← TODO: 설명` (추후 작성 표시)

### 7. 페이지 하단

- `---` 수평선 후 Author 표기
- 형식: `*Author: 이름 · 직책, 팀*`
