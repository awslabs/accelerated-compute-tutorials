# 고객 사례

AWS Trainium/Inferentia는 출시 이후 다양한 산업과 규모의 기업들로부터 빠르게 채택되고 있습니다. AI 스타트업부터 글로벌 엔터프라이즈까지, 대규모 언어 모델 학습과 추론 워크로드에서 뛰어난 가격 대비 성능을 경험한 고객들이 AWS 자체 설계 칩으로의 전환을 가속화하고 있습니다. 특히 Anthopic, OpenAI, ByteDance, Amazon Bedrock 등에서 수백만 대의 Trainium을 통해 비즈니스 성과를 달성하고 있습니다.

- **Anthropic** — Claude 모델 학습·배포에 100만 대 이상 Trainium(~1GW) 운영. Trn2 기반 Claude Sonnet 4.5, 타사 대비 1.4배 높은 Output Token/s. [5GW 추가 파트너십 체결 (2026년 4월)](https://www.anthropic.com/news/anthropic-amazon-compute)
- **OpenAI** — 차세대 Frontier·Stateful Runtime 워크로드를 위해 2GW Trainium 확보 합의
- **ByteDance** — Inferentia2로 하루 수십억 건 비디오 컨텐츠 분석 비용 50% 절감
- **Amazon Bedrock** — 전체 토큰 처리량의 50% 이상이 Trainium 기반으로 운영

아래에서 Trainium/Inferentia를 활용해 성능 개선 및 비용 최적화를 달성한 고객들의 생생한 후기를 확인해보세요.
