## Flexible AI on EKS Roadshow

:material-play-circle:{ .lg } **Flexible AI Solution: Building a Flexible AI Platform and Agentic AI Workloads on Amazon EKS** :flag_kr:{ title="Korean" }

!!! note "Course Information"
    **Format:** AWS Skill Builder online course (free, open to everyone)<br>
    **Language:** 🇰🇷 Korean<br>
    **Length:** 7 sessions

[:octicons-arrow-right-24: Take the course on AWS Skill Builder](https://skillbuilder.aws/learn/3RFUQ1H9J2/flexible-ai-solution-amazon-eks---ai--agentic-ai----/JV1VE53691){ .md-button .md-button--primary }

**Learning Objectives**

- Understand self-hosted AI trends — infrastructure strategies driven by data sovereignty, cost control, and customization needs
- Build a unified AI platform on EKS — run training, inference, and agents in a single cluster
- Deploy agentic AI to production — design deployment architectures for AI agents that autonomously reason, plan, and act
- Optimize cost and compute — chip selection, model quantization, Spot, storage optimization, and hybrid strategies
- Hands-on practice deploying a GenAI agent platform
