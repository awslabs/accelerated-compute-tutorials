# Neuron Explorer

This tutorial guides you through collecting profiles with Neuron Profiler and performing visual analysis with Neuron Explorer.

---

## Overview

Neuron Explorer is a tool for visually analyzing execution timelines, memory usage, and compute efficiency of workloads running on Neuron devices.

## Prerequisites
